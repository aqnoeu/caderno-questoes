# Claude — Caderno de Questões

Siga `AGENTS.md` antes de editar qualquer arquivo, incluindo as regras de backup por versão, changelog e uso do Prettier.

Para arquivos novos de código, execute `npm run format -- caminho/do/arquivo` antes do commit. Não faça formatação geral dos arquivos antigos na mesma atualização funcional. Verifique o diff e execute `npm run build`.
